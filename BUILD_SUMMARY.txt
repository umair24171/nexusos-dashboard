=============================================================================
GETTING STARTED
=============================================================================

1. Install dependencies:
   npm install

2. Setup environment variables:
   cp .env.example .env.local
   # Update NEXT_PUBLIC_API_URL and NEXT_PUBLIC_WS_URL

3. Start development server:
   npm run dev

4. Open browser:
   http://localhost:3000

5. Build for production:
   npm run build
   npm start

=============================================================================
AUTHENTICATION FLOW
=============================================================================

1. User logs in → POST /auth/login
2. Response contains: accessToken, refreshToken, user
3. Tokens stored in localStorage
4. axios interceptor adds "Authorization: Bearer <token>" to all requests
5. On 401 response, automatic token refresh attempt
6. Failed refresh redirects to /login
7. User data cached in localStorage

=============================================================================
WebSocket EVENTS
=============================================================================

Client emits:
- subscribe: { channel: "logs" }

Server broadcasts:
- log: AuditLog object

LiveFeed component auto-subscribes on mount and displays last 20 events.
